# Kodeonsdag 11.11. · Fra prototype til samarbeid

Vi starter kl. 16.00 og holder på utover ettermiddagen. Det blir pizza! 🍕

Vi bruker en liten versjon av Bumle, en app for lommepenger, til å utforske Visual Studio Code og Git. Du får gjøre en synlig endring, forstå hva som ble endret, lagre den i Git og dele den med en kollega.

Du trenger ikke være koder for å delta. Vi tar det steg for steg og hjelper hverandre. Det er også helt fint å jobbe med egne prosjekter.

## Før du kommer

Ta med PC eller Mac og følg [oppsettsguiden](https://github.com/avoconsulting/avo-pocketmoney/blob/main/docs/01-kom-i-gang.md). Den forklarer installasjon av VS Code, Git, Node.js og prosjektpakkene, og hvordan du sjekker at alt fungerer. Ingen betalte tjenester er nødvendige.

**Har du spørsmål eller står fast med oppsettet, si fra til Julie, så får du hjelp!** Du kan delta selv om du ikke har fått oppsettet til; vi finner en makker og løser det sammen.
